# The Living Handbook

Живая статья для новичка-вайбкодера и MCP для его агента. Предложения правок проходят Jev-оценку, согласование текста и явную авторскую публикацию.

**[Демо](https://the-living-handbook.fit-hake-0747.chatgpt.site/) · [English README](README.md) · [Статья](content/ARTICLE.ru.md)**

![Первый экран](docs/images/site.jpg)

Проект помогает понять цену тестов, рефакторинга, оптимизации и усложнения небольшого приложения. Сайт и MCP используют один опубликованный снимок; последнее слово остаётся за человеком.

## Запуск

Требуется Node.js 22.14+ и npm. Проверенный локальный runtime — 22.14.0.

```sh
npm ci
npm run check
npm run preview
```

http://127.0.0.1:3891/ — статья; /admin — тестовый авторский интерфейс. Preview сам подставляет тестового автора, использует настоящую SQLite в .sites-runtime и не загружает .env или платные ключи. Этот адаптер нельзя выдавать за production-авторизацию.

## Реализация

Одна актуальная версия Workers/D1, без дублирования старого Next.js-проекта. Интерфейс и статья RU/EN, вход ChatGPT, черновик после входа, предложения выделением и обычной кнопкой, очередь, редактор, история/rollback. Jev: typesafe/jev-1.14 через Decisions API OpenRouter; Writer: выбранный Claude Haiku 5.5. Один OpenRouter key может использоваться обеими моделями. Ключи вводятся только на своём сервере.

Четыре новых допуска в скользящий час на весь сайт; остальные предложения ждут без AI. Цитата и замена до 1500 символов, пояснение до 500. Общий предел 300 вызовов/UTC-сутки учитывает ошибки, повторы и переводы.

Хостинг демо — Sites: Worker + D1. Авторизация, служебные заголовки, вход и облачное расписание зависят от платформы. Для своего хоста нужны соответствующие адаптеры. [Размещение](docs/DEPLOYMENT.md), [MCP](docs/MCP.md), [архитектура](docs/ARCHITECTURE.md).

## Границы готовности

Проект — experimental MVP. Пороги Jev не откалиброваны; статья — редакционный черновик, EN — AI-перевод. Публикация всегда ручная. Ежечасное расписание демо настроено, но устойчивость работы без присмотра ещё не подтверждена. Внешний hosted MCP/OAuth, восстановление backup D1 и будущие карточки решений остаются задачами. Исходный автоматический Jev-отбор литературы не запускался.

Автотесты используют fixture-ответы провайдеров и реальную временную SQLite. Реальный полный перевод демо выполнен отдельно. [Первый GitHub CI прошёл успешно](https://github.com/Bb-soil/the-living-handbook/actions/runs/41513088580): чистая установка и полный набор проверок на Linux/Node.js 22. [План](ROADMAP.md).
