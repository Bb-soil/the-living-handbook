Подключение моделей
Ключи вводятся здесь, не в чат. Они отправляются только на сервер этого сайта и хранятся в зашифрованном виде. Пустое поле сохраняет прежний ключ. Сохранение настроек не вызывает модели и не тратит API-бюджет.
Jev: typesafe/jev-1.14 через Decisions API OpenRouter. Этот же ключ используется для Claude Haiku 5.5.
Jev не пишет связный текст. Для автоматического согласования нужен отдельный Writer с Chat Completions API. Пока он не подключён, Jev проверяет предложение, а автор согласует раздел вручную. Выбрано: Claude Haiku 5.5 через OpenRouter. При пустом поле отдельного ключа используется общий ключ OpenRouter.
