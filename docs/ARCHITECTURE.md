# Architecture

One Worker serves the article, protected author UI, JSON endpoints and two read-only MCP tools. D1 stores current publication, immutable revisions and candidates, submissions, model runs, encrypted settings and translation parts. Generated pages are build output; worker/pages.js is regenerated by npm run build.

Submission → deterministic checks → FIFO hourly admission → Jev moderate → Writer → Jev validate → human comparison/approval → atomic publication. Technical provider errors are not semantic rejection. New current revisions invalidate stale candidates. Rollback creates another revision.

RU is the editorial source. EN is assembled only when all parts match one source content_hash. Unchanged parts are reused by content hash; a stale translation is never presented as current. MCP returns the same source hash and a separate translation_hash.

Requests advance processing; a linked Sites cloud task calls the protected queue endpoint hourly while the site is closed. This repository does not install or claim a native Cron Trigger. Provider calls are capped and recorded. Nothing auto-publishes.

The local SQLite D1 adapter is test infrastructure. Sites dispatch supplies trusted identity; an untrusted external client must not be allowed to supply those headers directly on another host.
