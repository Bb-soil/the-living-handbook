# Draft release notes: v0.1.0 — experimental MVP

A living article for beginner vibe coders and a read-only MCP server their agents can use.

- Russian and English article: introduction, 15 sections and 55 sources.
- Suggestions from selected text, ChatGPT sign-in and restoration of a draft after sign-in.
- Jev evaluation through OpenRouter, optional Claude Haiku 5.5 rewriting and a separate result check.
- Author review, immutable history/candidates, explicit publication, conflict detection and rollback.
- FIFO queue with four new admissions per sliding hour, bounded text and provider budgets.
- MCP article/section tools with pinned revisions and language selection.
- Local SQLite-backed fixture tests and a prepared GitHub Actions workflow.

**Demo:** https://the-living-handbook.fit-hake-0747.chatgpt.site/

This is an experimental release, not a guarantee of safe autonomous editing. Publication is always approved by the author. Jev thresholds are provisional, the article remains an editorial draft, and English is AI-translated. Repeated unattended execution, hosted MCP/OAuth clients and D1 restore still need verification. Hosted identity and scheduling use Sites integrations.
