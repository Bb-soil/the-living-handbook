# The Living Handbook

Статья для новичка-вайбкодера и его ИИ-агента: как делать небольшие проекты, понимать решения и проверять результат.

**[Читать на сайте](https://the-living-handbook.fit-hake-0747.chatgpt.site/) · [Статья на русском](ARTICLE.ru.md) · [English article](ARTICLE.en.md) · [Источники](SOURCES.md)**

## Зачем

«Добавил тесты, провёл рефакторинг, оптимизировал архитектуру» — ещё не объяснение пользы. Справочник помогает новичку обсуждать с агентом конкретные риски, цену решений и критерии готовности, сохраняя последнее слово за человеком.

## Что внутри

Введение и 15 разделов: объём MVP, постановка задачи, структура проекта, Git и секреты, контекст агента, сложность, тесты, проверка результата, безопасность, рефакторинг, оптимизация, развитие и словарь. В конце — 55 источников. На обычное чтение ориентировочно 30–40 минут.

## Статус

Редакционный черновик: `draft_for_author_review`. Снимок опубликованной ревизии **1**. Английский текст — AI-перевод с автоматическими проверками, без полной независимой лингвистической экспертизы. [Редакторские заметки](EDITORIAL_NOTES.md).

## Как связан с сайтом и MCP

На сайте можно выделить текст и предложить правку. Jev оценивает предложение, Writer согласует текст, а автор подтверждает публикацию. MCP читает опубликованный снимок статьи; будущие компактные карточки решений пока не реализованы. Подключение клиента может требовать отдельной авторизации Sites.

Этот комплект — **статья и её данные, без кода приложения**. Он не запускает сайт или MCP и не синхронизируется с ними автоматически. Обновления на GitHub нужно переносить через авторскую публикацию и повторный экспорт.
