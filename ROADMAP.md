# Roadmap

## Implemented

- [x] RU/EN reader, source references, language switching and public demo.
- [x] Selection-based suggestions, sign-in entry points and draft restoration.
- [x] Author editor, immutable candidates/history, explicit publication, conflicts and rollback.
- [x] Jev/Writer adapters, result check, analytics, encrypted settings and budgets.
- [x] FIFO admission, four new suggestions/hour globally and protected background endpoint.
- [x] Read-only MCP, pinned revisions and language selection.
- [x] Build, protocol/content smoke and SQLite-backed fixture test suites.

- [ ] Restore a D1 backup into an independent instance.
- [ ] Review English translation and approve editorial text.
- [ ] Run the prepared CI on the actual GitHub repository.
- [ ] Add compact agent decision cards linked to article revisions if useful.

Auto-publication, multiple authors, vector search and distributed infrastructure are outside the current MVP.
